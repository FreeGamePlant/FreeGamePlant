# Security Policy — Free Game Plant (FGP)

## Reporting a Vulnerability

The Free Game Plant (FGP) takes the security of its projects and users seriously.

If you discover a potential security vulnerability in this repository or in the official FGP website, please report it responsibly.

**Contact:**  
Free Game Plant (FGP)  
Email: elaifigueroa@gmail.com

## Responsible Disclosure

To help protect the project and its users, please:

- Do not publicly disclose an unpatched vulnerability.
- Do not exploit vulnerabilities or access data without authorization.
- Provide a clear description of the issue and, when possible, steps to reproduce it safely.
- Avoid actions that could disrupt the website or its services.

## Security Updates

Reported vulnerabilities will be reviewed and investigated as availability permits.

If a vulnerability is confirmed, appropriate corrective measures may be implemented and published through repository updates.

## Scope

This policy applies to:

- The official Free Game Plant website.
- The source code contained in this repository.
- Website features and resources maintained by FGP within this project.

Third-party services, libraries, and platforms are subject to their respective security policies.

## Important Notice

Free Game Plant does not currently operate a formal bug bounty program. Reporting a vulnerability does not guarantee financial compensation or a specific response time.

Thank you for helping keep Free Game Plant safer.
